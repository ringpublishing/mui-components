# Material → lucide icon map

Replacements for the Material icons used in Ring Publishing modules, by `@mui/icons-material` export or Material Icons
font name. Search by either name, an import path or a local name such as `DeleteIcon`, and import the icon by the name in
the second column from `lucide-react` (`import { Trash2 } from 'lucide-react';`), or from
`@ringpublishing/mui-components/icons` where the row says so, for a glyph lucide does not ship. For an icon not listed,
find its equivalent on [lucide.dev](https://lucide.dev/icons/).
