# FiltersWrapper

A themed wrapper component for organizing filter controls with an optional clear button and customizable styling. It provides consistent theming for child form elements.

- Configurable label and clear button with callback
- Themed child elements via `variant` and `size` props
- Supports standard, outlined, and filled input variants
- Customizable button styling via `buttonStyle` prop
- Works with Accordion, DatePicker, TextField, Checkbox, Switch, Radio, Select, Slider, and custom inputs

## How Theming Works

FiltersWrapper uses a MUI `ThemeProvider` to override default props for child MUI components, not for the wrapper itself.

- Inputs default to `variant="outlined"`, MUI X date and time fields included; `variant={VariantEnum.STANDARD}` renders standard inputs.
- `size` also reaches Autocomplete, Checkbox, Radio, Switch and Slider.
- `buttonStyle` sets child buttons; the clear button stays a medium text button.
- The label renders `subtitle1`.
- Inside, the Accordion card has no shadow and its content runs edge to edge.
