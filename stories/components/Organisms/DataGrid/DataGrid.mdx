# DataGrid

An enhanced data grid component built on top of MUI X DataGrid.
**Features:**

- Custom toolbar with refresh, auto-refresh toggle, sorting, and additional components
- Bulk actions mode with select all/deselect all and configurable max selection
- Built-in custom cell renderers: combo cell, link cell, action cell, and spacer rows
- Auto-refresh with configurable rate, user interaction debounce, and initial state
- Filter chips group for active filter display
- Checkbox selection with optional disabled select-all header
- Error and no-results placeholder states

## Custom toolbar

## Bulk actions

Enables bulk operation mode with checkbox selection, select all/deselect all, and configurable bulk action buttons (e.g., Delete, Edit). The `maxSelectedRowsCount` limits the number of selectable rows.

<Canvas of={Stories.BulkActions} />

## Classic selection

Checkbox selection with `disableSelectAllCheckbox` set to `true`, removing the header checkbox. Uses a controlled `rowSelectionModel` with `clearSelectionOnRefresh` disabled.

<Canvas of={Stories.ClassicSelection} />

## Auto refresh — active

Auto-refresh enabled with a 5-second interval. User interactions (mouse, touch, scroll) temporarily pause refresh with a configurable debounce delay.

<Canvas of={Stories.AutoRefreshActive} />

## Auto refresh — never paused

Auto-refresh with `disableAutoRefreshOnUserInteraction` set to `false` — the grid continues refreshing regardless of user interaction.

<Canvas of={Stories.AutoRefreshIgnoreInteraction} />

## Auto refresh — initially off

Auto-refresh is configured but starts disabled via `initialState.autoRefreshEnabled: false`. The user can enable it manually via the toolbar toggle.

<Canvas of={Stories.AutoRefreshInitiallyDisabled} />

## Auto refresh — disabled

No auto-refresh configuration — the grid only refreshes on manual user action.

`placeholderLabels.empty` overrides the header and description of the "no results" placeholder, so the message can name what the grid lists (articles, assets) and suggest the next step. Labels not overridden keep the built-in translation.
