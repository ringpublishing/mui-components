# DateTimePicker

A combined date and time selection component that wraps MUI X's [DateTimePicker](https://mui.com/x/react-date-pickers/date-time-picker/). The field is MUI X's default `outlined`; `slotProps={{ textField: { variant: 'standard' } }}` renders a standard field. Allows users to pick both a date and time in a single input with a unified popup.

- Clearable input with calendar icon
- Combined date and time selection in one popup
- Configurable label
- Custom actions in a "More actions" menu via the `actions` prop
- Extends all MUI DateTimePicker props
- Supports `sx` and `className` for custom styling

## Prerequisites

DateTimePicker requires a `LocalizationProvider` wrapper with a date adapter. Set this up once at the root of your application:

```tsx
import { LocalizationProvider } from '@mui/x-date-pickers-pro';
import { AdapterDayjs } from '@mui/x-date-pickers-pro/AdapterDayjs';
import 'dayjs/locale/en';

function App() {
    return (
        <LocalizationProvider dateAdapter={AdapterDayjs} adapterLocale="en">
            {/* Your app content */}
        </LocalizationProvider>
    );
}
```

## Actions

`actions` adds a "More actions" menu at the field's end, beside a clear button. Each action has a `label` and optional `onClick`, `icon`, `disabled`, `disabledReason`. An empty array is the same as omitting `actions`.

```tsx
<DateTimePicker
    actions={[
        { label: 'Copy', onClick: () => handleCopy() },
        { label: 'Share', onClick: () => handleShare() },
    ]}
/>
```
