# TextField

TextField extends [MUI Text Field](https://mui.com/material-ui/react-text-field) component and supports all its properties. It adds support for contextual **actions** rendered as icon buttons in the field's end adornment.

**Key Features:**

- Single action rendered as a standalone icon button with tooltip
- Multiple actions collapsed into an `EllipsisVertical` menu via `ActionBox`
- Full MUI TextField API support (variants, sizes, states, etc.)
- Controlled and uncontrolled usage patterns

## Long value

A value longer than the field. A single-line field keeps the value on one line and cuts it off
before the button; a multiline field wraps it.

- **Copy** — put a `CopyIconButton` in the end adornment, as in the Canonical URL field. It confirms the copy with a
  check glyph and falls back to a hidden textarea where the browser blocks the clipboard API.
- **Any other icon** — pass it through `actions`, as the AI action of the Lead field does.
- **No icon** — a multiline field needs none to hold a long value, as the Note field shows. With `minRows` and
  `maxRows` it grows as the text grows and scrolls past the last row.

The field sizes the button (24px in a small field, 28px in a medium one) and keeps it at the right edge, in a
single-line and a multiline field alike.
