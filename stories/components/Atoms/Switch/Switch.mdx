# Switch

Switch toggles the state of a single setting on or off. Its look — a thumb travelling inside a
tall pill track, with all colors from the design system palette — lives in the theme, so a plain
MUI Switch renders it too; this wrapper adds Ring test ids and narrows the color variants.

## Key Features

- pill track with the thumb fully inside it, in `medium` and `small` sizes
- `primary` (default) and `error` colors
- colors resolved from the theme palette — adapts to light and dark mode
- `data-testid` on the root and on the underlying input
